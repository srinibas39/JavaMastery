# Variables
- container which holds a value
```
String name = "John";
```

- Java is static type --> variable has a data type
- Java is strong type --> Each data type has a range

## Types of variable

- Primitive and Non-primitive


## primitive

- char - 2 bytes , Range --> 0. to 65535
```
char v = 97; --> a
char v = 65; --> A
```
- byte - 1 byte , Range --> -128 to 127 [default = 0]
 -ve is represented by 2's compilment
 default value only assigned to class level

- int - 4 bytes , Range --> - 2^31 to 2^31 -1 (default - 0)

- short - 2 bytes , Range --> -32788 to -32767

- long - 8 btes , Range --> 2^63 to 2^63 - 1

- float - 32 bit IEEE754 values 
- double - 64 bit IEEE754 values

 In Industry Big Integer is preferred instead of float and double

- boolean --> true / false; 1 bit [default - false]
